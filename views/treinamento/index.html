Sobre o treinamento

Neste treinamento você desenvolverá habilidades relacionadas à utilização de recursos avançados do Microsoft Excel.

As atividades deverão ser realizadas fora do portal. Após concluir cada atividade, envie o arquivo solicitado para registrar sua conclusão.

Atividades do treinamento

Realize as atividades e anexe os arquivos solicitados.

Atividade 01

Leia o material introdutório

Pendente

Leia o documento sobre funções avançadas do Excel disponibilizado pela empresa.

Introdução ao Excel Avançado.pdf Material de apoio • PDF
Atividade 02

Crie uma planilha de controle financeiro

Pendente

Crie uma planilha contendo receitas, despesas, saldo mensal e total anual.

A planilha deverá conter:
  • Colunas para receitas e despesas;
  • Fórmula automática para cálculo do saldo;
  • Total mensal;
  • Gráfico comparando receitas e despesas.
Atividade 03

Crie uma tabela dinâmica

Pendente

Utilize uma base de dados de exemplo e desenvolva uma tabela dinâmica para análise das informações.

Atividade 04

Desenvolva um relatório final

Pendente

Crie um arquivo contendo uma breve análise sobre os dados utilizados nas atividades anteriores.

Treinamento concluído! Todas as atividades foram realizadas.
